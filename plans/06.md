### Phase 2 Integration Notes
- Storage driver selector: `STORAGE_DRIVER` env var (`local-disk` or `s3-compatible`)
- Media files stored in `media-storage/` directory (local) or S3-compatible endpoint
- Job queue: main SQLite database `jobs` table
- Worker polls every 5 seconds, processes `pending` jobs, marks as `done` or `failed`
- Image processing: sharp for resize/thumbnail generation
- Video processing: fluent-ffmpeg for thumbnail extraction and transcoding
- Socket.io events: `media:ready` emitted when processing complete
- Job handlers: `generateThumbnail.js`, `transcodeVideo.js`, `rollupAnalytics.js`
